# 抓龙助手 ⚽

一个**本地运行的网页应用**：每天自动与中国体育彩票中心官方公开接口同步当天开售的
**竞彩足球**（胜平负、总进球、比分、半全场）与**传统足彩**
（胜负彩14场、任选9场、6场半全场、4场进球）赛程与赔率，用内置分析引擎
**自动为每一种玩法生成一张投注方案卡片**（八种玩法同一面板展示），
支持手动点选修改、投注单汇总（复制文本/生成截图发给彩票店）、
每日预算控制、历史记录与盈亏统计。

> 纯 Python 标准库实现，**零第三方依赖**，浏览器访问即用。明亮浅色主题。

---

## 快速开始

```bash
cd zucai-dashboard
./run.sh
# 或: python3 server.py
```

浏览器自动打开 **http://127.0.0.1:8456**（不会自动打开时手动访问即可）。

- 换端口：`PORT=9000 ./run.sh` 或 `python3 server.py --port 9000`
- 强制指定数据源：`python3 server.py --pref demo`（演示数据）/ `--pref official`（仅官方）/ `--pref fallback`（备用源）
- 需要 Python 3.9+，macOS 自带即可，无需 pip install

## 数据源（自动降级链）

| 玩法 | 官方（主） | 备用 | 兜底 |
|---|---|---|---|
| 竞彩足球（胜平负/总进球/比分/半全场） | sporttery 官方 webapi（含全部赔率） | 500.com 官方赔率同步镜像（含全部4种玩法） | 内置演示数据 |
| 胜负彩14场 / 任选9场 | sporttery 官方 webapi | okooo 澳客网 | 内置演示数据 |
| 6场半全场 / 4场进球 | sporttery 官方 webapi | （暂无备用） | 内置演示数据 |

- **官方接口只在中国大陆正常网络可用**（境外/服务器 IP 会被 WAF 以 HTTP 567 拒绝）。
  你在家里/手机网络运行即可用官方数据；用不了时程序自动降级并明确提示。
- **赔率以中国体育彩票中心官方为准**：备用源 500.com 展示的正是体彩中心赔率（胜平负/总进球/比分/半全场 4 种玩法全部同步）；
  极端情况下（连备用源都没有该玩法赔率）引擎才用胜平负推导估算，并标注"🛠 估算值"。
- 界面右上角显示每个数据源当前状态；"设置 → 数据源"可手动切换（自动/官方/备用/演示）。
- 程序每 10 分钟自动刷新一次，也可点右上角"⟳ 刷新"。
- 首次在你自己电脑运行时，建议先跑一下官方接口探测：
  ```bash
  python3 tools/probe_sporttery.py
  ```
  把输出发给我，可帮你校准传统足彩官方端点。

## 玩法卡片（八种，同一面板）

1. **竞彩·胜平负**：每场 胜/平/负 赔率按钮；引擎标出 首选/稳胆/价值/冷门，给单关仓位（1/4 凯利）与 2串1 串关建议
2. **竞彩·总进球**：0~7+ 球概率分布，提示大/小球倾向
3. **竞彩·比分**：默认显示每场高概率的前6个比分（3×6网格），点"展开全部比分"看全部 31 个
4. **竞彩·半全场**：9 种半场/全场组合（3×3 网格），推荐前2
5. **胜负彩(14场)**：按欧指概率给每场 胆/稳/博 分级，自动生成复式（胆拖）方案并计算注数
6. **任选9场**：从14场中自动选出概率最高的9场，复式
7. **6场半全场**：6 场 × 9 组合，自动推荐
8. **4场进球**：8 支球队 × 0/1/2/3+ 进球，泊松分布推荐

场次统一按「周六001 法甲 A VS B」的写法展示，并显示**星期+日期+开赛时间**（如"周六 08-22 22:00"）；
竞彩卡片顶部有**日期筛选条**（全部/周六/周日…），点选只看当天场次。

每张卡片都有 **"采用推荐"** 和 **"手动"** 两个按钮：
- **采用推荐**：把该卡片引擎推荐的选项加入投注单
- **手动**：该卡片进入手动模式——清掉自动选择、隐藏推荐高亮，全部由你点选
- 顶部 **"✨ 一键推荐（最有把握）"**：按"最有把握"模式重算（只推高概率/稳胆选项，复式收敛为单注），再全部采用
- 顶部另有 **"一键采用全部手动"**（全部卡片进入手动模式，投注单清空）

## 过关串关（与体彩中心玩法同步）

**每张竞彩卡片都有"过关模式"**（日期筛选条下方）：
- 可选 **单关 / 2串1 ~ 8串1**（同一玩法过关最高 **8串1**，与体彩中心规则一致）
- 选好"几串几"后，在该卡片上点选场次选项，卡片实时显示**过关票**：注数（自由过关+复式，按体彩规则计算）、金额、预计奖金，并直接进入投注单
- 场次不足时会提示"至少选 M 场"；注数超限（>5000注）会阻止生成并提示减少场次
- 切换回"单关"即恢复单场投注

**另外还有：**
- **自动串关推荐**：引擎从胜平负的高概率选项里自动生成 **2串1、3串1** 过关建议（每注2元），勾选即可加入
- **混合过关生成器（投注单内）**：跨玩法混合过关，**最高 4串1**（体彩规则），每场限一种玩法；已设置过关模式的卡片不参与混合过关
- 规则提示：同一玩法最高 8串1、混合过关最高 4串1、仅标记"单关"的场次可单场投注

## 预测成功率与预计奖金

每张卡片顶部有一个 **📊 预测成功率 + 💰 预计奖金** 面板，随你的选择**实时更新**：
- **竞彩单关**：显示"单注平均命中率"（当前各注概率的平均值）+ **预计奖金范围**（固定奖金：
  最低=只中最小那注，最高=全部命中之和，按"投注额×赔率"精确计算）
- **串关/过关票**：每注 2元×组合赔率，同样给出精确的 最低~最高 奖金范围
- **传统复式（胜负彩/任九/半全场/进球）**：显示"整票全中概率"+"平均单场命中率"+
  **预计奖金（估算）**——传统足彩是奖池玩法，实际奖金由当期销量与中奖注数决定，
  这里按中奖难度折算历史常见奖金带（如胜负彩14场一等约3万~100万），**仅作参考，以开奖为准**
- 数字按大小显示绿/黄/红三色，附进度条；命中率极低时如实显示为 `<0.1%`

> 提醒：成功率只是"推荐方案按概率模型的置信度"，不代表中奖保证——胜负彩14场单注全中概率天然极低，复式就是为提升它而存在的；竞彩单关平均命中 40-50% 已经算不错，但长期期望仍为负。

## 投注单

- 所有卡片选中的注汇总到右下角投注单，实时计算 **注数×金额** 并与每日预算比对（超预算变红提示）
- **复制文本**：一键复制投注明细，直接粘贴到微信发给彩票店
- **生成截图**：渲染成 PNG 图片保存到下载目录，发给彩票店
- **保存历史**：存入本地 SQLite（data/zucai.db），"历史"里可标记 中/未中 并记盈亏

## 设置

- **今日预算**：顶栏可拖动滑块或**直接输入金额**（默认100元），调预算即时重算各玩法分配
- **八种玩法权重**：设置里可改（默认：胜平负15% 总进球6% 比分6% 半全场6% 胜负彩25% 任九20% 半全场11% 进球11%）
- **数据源**：自动/官方/备用/演示
- **大模型深度分析（可选）**：填入你自己的 OpenAI 兼容 API（DeepSeek/OpenAI/Kimi/Qwen 等）地址、模型、Key，
  点"分析当前数据"让大模型给出深度方案。Key 只存在**本浏览器 localStorage**，请求直接从你的电脑发给
  你配置的服务，不经过任何第三方。没有 Key 也能用内置引擎。

## 内置分析引擎说明（诚实声明）

- **没有任何程序能预测足球比赛**。彩票长期是**负期望**游戏（公益金+发行费占比高）。
- 引擎做的是三件实事：把赔率换算成可解释的概率、用 **1/4 凯利** 控制单注仓位、
  用预算分配把每天 50-100 元分散到各玩法——**目的是减少损失、规范流程，不是保证盈利**。
- 所有推荐都带概率/标签/理由，你可以完全手动修改。

## 项目结构

```
zucai-dashboard/
├── server.py            # 本地 Web 服务（HTTP+API+缓存+SQLite+LLM代理）
├── sources.py           # 数据源：官方接口/500.com/okooo/演示，四级降级
├── engine.py            # 分析引擎：概率/价值/凯利/九种玩法方案/LLM
├── web/                 # 前端（index.html / style.css / app.js，无构建）
├── mock/gen_demo.py     # 演示数据生成器（双泊松模型）
├── mock/demo_data.json  # 生成的演示数据
├── tools/probe_sporttery.py  # 官方接口探测工具
├── run.sh               # 一键启动
└── data/                # 运行时自动生成：缓存 + zucai.db 历史
```

## 隐私与安全

- 服务只绑定 **127.0.0.1**，仅本机可访问，不上传任何数据。
- 你的数据源请求直接发给体彩官方/备用源；大模型 Key 仅存本机浏览器。

## 部署到 Render（云端，手机/电脑随时访问）

> ⚠️ **重要前提**：Render 服务器在美国，**体彩官方接口会被 WAF 封禁（HTTP 567）**，
> 部署到云端后自动降级到 **500.com / okooo 备用源**（赔率同样是体彩中心同步镜像）。
> 想要官方直连数据，仍建议在本机（中国大陆网络）运行 `./run.sh`。
> 另外 Render 免费版实例闲置 15 分钟会休眠，首次访问约需 30~60 秒唤醒；历史记录存在临时磁盘，重启后会清空。

**方式一：Blueprint 一键部署（推荐）**
1. 把本项目推到你的 GitHub 仓库（`git init` → `git add .` → `git commit` → 推送到 GitHub）
2. 打开 [render.com](https://render.com) 注册/登录（免费）
3. 控制台 → **New → Blueprint** → 填入 GitHub 仓库地址 → Apply
4. 项目里的 `render.yaml` 会自动创建 Web 服务，完成后访问 `https://zhualong-assistant.onrender.com`

**方式二：手动创建 Web Service**
1. 同样先把代码推到 GitHub
2. Render 控制台 → **New → Web Service** → 连接仓库
3. 填：Runtime `Python`、Build Command 留空、Start Command：
   ```
   python3 server.py --host 0.0.0.0 --no-browser
   ```
4. 选 Free 实例 → Create

部署文件已备好：`render.yaml`（Blueprint 配置）、`requirements.txt`（纯标准库，无第三方依赖）、`.gitignore`（排除 data/ 缓存与历史）。

## 常见问题

- **打开页面后提示"演示数据"**：说明官方接口在你当前网络不可用（如公司网络/代理/境外服务器）。
  换家庭网络再刷新，或点设置把数据源切到"官方接口"。
- **传统足彩显示"部分玩法为演示数据"**：备用源（okooo）只有胜负彩/任九，6场半全场、
  4场进球需官方接口；在中国大陆网络下会自动用官方。
- **端口被占用**：`python3 server.py --port 9000`
- **想改分配比例**：设置里改权重，保存后自动重算。
